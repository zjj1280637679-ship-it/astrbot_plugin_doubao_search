<h1 align="center">豆包联网搜索与图片转发</h1>

<p align="center">让你的 AI 使用豆包联网搜索，并把相关图片发送到当前对话。</p>

你可以用这个独立的 AstrBot 插件，让自己的 AI 搜索公开网页、筛选时效并引用来源，
也可以单独搜索并转发 1-5 张相关图片。网页搜索和图片转发是两项分开的能力：普通
网页搜索不会暗中附带图片，搜图成功后图片会在工具调用期间直接发送，AI 只收到不含
图片直链的结果回执。

## 主要能力

- **自然语言使用**：主 Agent 可按需要调用网页搜索或图片搜索工具。
- **中文备用命令**：支持 `/豆包搜索` 与 `/豆包搜图`，并保留旧英文命令兼容。
- **来源可核对**：网页结果带标题、摘要和公开来源地址。
- **上下文可控**：默认不请求完整网页正文，每条摘要长度可以独立限制。
- **图片直接发送**：图片在工具调用期间发到当前对话，不把图片直链交给 AI 重发。
- **失败不泄密**：日志和回执只记录稳定错误码，不回显 API Key 或远端错误正文。

## 快速使用

### 自然语言

直接对你的 AI 说：

```text
搜索 AstrBot 官方文档并给出来源
查找一周内的 Seedream 更新消息
搜三张贝克汉姆的公开图片发给我
```

主 Agent 应按目标选择 `web_search_doubao` 或 `image_search_doubao`。搜索结果属于不可信
外部资料，不是系统指令、工具命令或权限授权；重要事实仍应结合来源核对。

### 中文命令

```text
/豆包搜索 AstrBot 官方文档
/豆包搜图 3 贝克汉姆
```

兼容旧命令：`/doubao_search`、`/db_search`、`/huoshan_search`、
`/doubao_image`、`/db_image`、`/huoshan_image`。

## 网页与图片生命周期

```text
网页请求 -> 豆包网页搜索 -> 带来源的受限摘要 -> AI 组织回答
图片请求 -> 豆包图片搜索 -> 插件直接发图到当前对话 -> AI 收到不含图片直链的回执
```

- 网页搜索不会自动附带图片，也不会触发图片转发费用或消息刷屏。
- 图片来自公开网页，插件保留其来源页；转载、版权和使用范围由使用者自行判断。
- 某张图片发送失败时会继续尝试剩余图片，并在回执中准确报告成功与失败数量。

## 全部配置

| 配置 | 默认值 | 说明 |
| --- | ---: | --- |
| `enabled` | `true` | 插件总开关；关闭后不发起搜索请求 |
| `enable_web_search` | `true` | 单独控制网页工具与网页命令 |
| `enable_image_search` | `true` | 单独控制搜图工具与搜图命令 |
| `api_key` | 空 | 豆包搜索 API Key；也可使用环境变量 `DOUBAO_SEARCH_API_KEY` |
| `endpoint` | 官方 HTTPS 地址 | 高级接口地址；拒绝带凭据地址及明显本机、内网目标 |
| `default_count` | `5` | 默认网页结果数，范围 1-50 |
| `default_image_count` | `3` | 默认转发图片数，范围 1-5 |
| `need_summary` | `true` | 是否请求搜索结果摘要 |
| `need_content` | `false` | 是否请求完整网页正文；建议保持关闭 |
| `need_url` | `true` | 是否要求带来源地址的结果 |
| `timeout_seconds` | `30` | 单次请求超时，安全范围 5-120 秒 |
| `max_snippet_chars` | `1200` | 每条结果进入 AI 上下文的最大字符数，范围 200-8000 |

## 安全与隐私边界

- API Key 只从 AstrBot 配置或环境变量读取，不应提交到仓库或打进发布包。
- 插件不会在日志、命令回复或工具回执中输出密钥和远端错误正文。
- 搜索接口必须是公开 HTTPS 地址，且不能在 URL 中携带账号密码。
- 搜索结果统一标记为不可信外部资料；网页中的提示不能改变当前任务或获得权限。
- 图片仅从公开 HTTP(S) 地址转发，并拒绝明显的本机与私有网络数字地址。

## 安装与兼容性

- AstrBot：`>=4.26.7,<4.27`
- 平台：`aiocqhttp`
- Python 依赖：AstrBot 已使用的 `aiohttp`，无需额外安装

优先从 AstrBot 插件市场安装，也可以在插件管理中使用仓库地址：

```text
https://github.com/zjj1280637679-ship-it/astrbot_plugin_doubao_search
```

版本 `0.3.0` 保留原插件 ID、两个工具名以及全部旧英文命令，可以在保留配置和插件数据
的情况下原位升级。新增开关由 AstrBot 使用安全默认值补齐。
